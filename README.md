# Trail Ta Bai — Investor Teaser

Public GitHub Pages site for the Trail Ta Bai angel / investor demo teaser.

**Live URL:** https://ccsavvy.github.io/trail-ta-bai-teaser/

Cinematic ~78s auto-play pitch matching the Trail Ta Bai Android MVP (forest green brand, Visayas trails & camps).

Published by **CCSavvy Studios** (LumaGad Tech creative label).

## Controls

| Key | Action |
|-----|--------|
| Space | Pause / Play |
| R | Replay |
| F | Fullscreen |
| H | Hide chrome (for clean recording) |

## Export to MP4 (macOS QuickTime)

1. Open the live URL, press **F**, then **H** to hide UI.
2. **QuickTime Player** → **File** → **New Screen Recording**.
3. Record the fullscreen teaser (~78s).
4. **File** → **Export As** → **1080p**.
